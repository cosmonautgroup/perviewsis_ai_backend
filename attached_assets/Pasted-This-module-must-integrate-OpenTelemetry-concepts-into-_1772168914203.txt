This module must integrate OpenTelemetry concepts into the existing Predictive Observability Platform and demonstrate vendor-neutral, AI-ready observability architecture.

The goal is to simulate an OpenTelemetry-based telemetry pipeline that:

• Ingests metrics, traces, and logs
• Routes through an OpenTelemetry Collector layer
• Supports multiple backend exporters (AppDynamics, Prometheus, Data Lake mock)
• Enables AI-driven causal and predictive insights
• Provides persona-based dashboards
